Difference between library and framework


Library 


Definition : Its a collection of pre -written code that you can call to perform specific task


Control: We can control the application flow.We can decide when and where we can call the library


Example:React is a library where developers used to structure the application and when to call React methods


Analogy : Think like a toolbox, pick a tool you need and use them as required.



Framework


Definition: A full fledged platform that provides structure and guidelines to develop the application


Control:The framework controls the application flow and calls our code at certain points.This is inversion of control


Example : Angular is a framework because it defines how you structure your application and comes with built in feature like 
routing,dependency injection.


Analogy:Its a template, you need to work within the predefined structure and rules.

What parcel will give us?
1. Dev build
2. Local Server
3. HMR - Hot Module Replacement
     Parcel uses the file-watching algorithm that is written in C++, this keeps track of all the files 
     whenever there is a file getting changed and saved it automatically refreshes the server
4. Faster builds
     It caches things for you so gives the faster build. It caches things in the .parcel-cache folder
5. Image optimization
     Parcel will do the image optimization as well, this is the highest operation in the browser - 
     this minifies and compresses this as well.
6. Minification
7. Bundling
8. Compressing
9. Consistent hashing
10. Code splitting
11. Differential bundling - to support older supports as well
12. Diagnostic - it gives good error suggestion
13. Error handling
14. Host apps on HTTPS as well - if you use npx parcel index.html https it will run the https for you
15. Tree Shaking algorithm - if we have 100's of functions in the code but we are using 4 functions - 
it will remove the unused code for you
16. Different dev and production bundles

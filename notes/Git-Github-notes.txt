##Git##

Git is a distributed version control system (VCS) used to track changes in files, typically source code. 
It enables developers to collaborate on projects, manage versions, and maintain a history of changes made to a codebase.

##Github##


GitHub is a cloud-based platform that uses Git for version control. 
It provides hosting for Git repositories and adds features for collaboration, project management, and deployment.

##commit hash(#)

This is unique number generating for each commit

##git commit -m "Message"

this  -m  is meant for Message

While you give the message some standards have to follow

Fix:message - if you are creating a commit that is related to issue fixes then this standard have to follow

Feat:message - if you are adding any new feature then use this

Refactor:message - If you are changing the already existing things like variable name, functionality use this

Docs:message - If you are adding the documentation for your code then use this

Chores:message - 

!Fix:message - IF you are adding this then this is a breaking fix that will affect other developers

##Merge conflicts

##git stash

If you are trying to add one line,but someone already added some changes in the same line.

Now before commiting you are trying git pull at that time you get the error

^^^^^Please commit your changes or stash them before you merge

So what we need to do now is to do git stash it will add your local changes to a bucket in a stack, if you want that stack you 
have to do git stash pop and get the latest stash - here also the merge conflict will come so here if needed accept your current change,
or accept both then your change+the change already there , based on the sitation accept that

then do git pull  the above error will not come
